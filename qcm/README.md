# Gros QCM – Cours théoriques BA701

QCM de révision (MVL, MVL en anglais, météo, DA, SB, CCM, navigation, PDV, HP).

- `index.html` : la page du QCM (ouvre-la dans un navigateur, ou via GitHub Pages).
- `data/*.json` : les questions, une banque par matière.
- `bank/*.py` : les sources des questions ; `python3 build.py --strict` régénère `data/`.

La progression (questions ratées, scores) est enregistrée dans le navigateur (localStorage).
